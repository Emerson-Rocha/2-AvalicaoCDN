# 📚 Atividade Prática – MongoDB: Schema Validation e Índices

## 🎯 Objetivo

Nesta atividade, serão explorados os recursos de validação de documentos e otimização de consultas no MongoDB, utilizando JSON Schema e índices.

## 📌 Descrição

A atividade consiste no desenvolvimento de um cenário de gerenciamento de produtos de uma loja de eletrônicos, aplicando mecanismos de validação para garantir a integridade dos dados e índices para melhorar o desempenho das consultas.

## 📖 Conteúdos

- Schema Validation (JSON Schema);
- Tipos de dados BSON;
- Campos obrigatórios (`required`);
- Validação de valores (`enum` e `minimum`);
- Inserção de documentos;
- Índices simples e compostos;
- Análise de consultas com `explain("executionStats")`;
- Comparação de desempenho.
